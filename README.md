# ai-tools
Some useful tools made by AI.

---

### 项目简介

本项目是一个工具集网站，收录用 AI 编程工具通过 VibeCoding 方式构建的各种有用的工具。

同时，工具集本身也由 AI 编程工具通过 VibeCoding 方式构建完成。

---

### 构建故事

在 TRAE Work 的 Work模式 提问：`我想做一个网站，收录我用AI VibeCoding出的产物，类似AI工具集，这个网站要怎么设计？`

AI的答复掐其精华如下：

```text
首页布局
顶部导航栏：Logo/站名 + 分类筛选标签（如 全部 / Web应用 / 小工具 / Chrome插件 / 自动化脚本 / 实验性项目）+ 搜索框 + 深色模式切换
Hero 区域（可选，但建议有）：一句有态度的 tagline，比如"用自然语言写出来的产品"，配一个动态背景或终端风格的 prompt 打字动画
作品卡片网格：这是主体。每个卡片包含：
产品截图/预览图
项目名称
一句话简介
技术标签（如 React / Python / Electron）
状态标签（已上线 / 开发中 / 实验性 / Archive）
hover 时浮出"查看详情"和"在线体验"两个按钮
卡片布局选择：推荐等高卡片 + CSS Grid 自适应列数（桌面 3-4 列，平板 2 列，手机 1 列）。瀑布流虽然好看，但信息密度不均匀，不适合工具导航场景
详情页
点击卡片进入，分为几个信息区块：

产品展示区：大图轮播或视频演示 + 在线体验链接（新窗口打开）
项目信息：名称、一句话描述、技术栈标签、创建时间、状态
功能说明：这个工具解决什么问题、核心功能列表
构建故事（重点差异化的部分）：原始 Prompt 是什么、用了什么 AI 工具（Cursor / Copilot / TRAE / ChatGPT 等）、迭代了几轮、遇到什么有趣的技术决策
```

经我小改，丢给 TRAE Work 的 Design模式 并使用21th设计系统，如下：

```text
用这个设计系统，做一个AI工具集网站

 首页布局：
 - 顶部导航栏：分类筛Logo/站名 + 选标签（如 全部 / Web应用 / 小工具 / Chrome插件 / 自动化脚本 / 实验性项目）+ 搜索框 + 深浅色模式切换
 - Hero 区域：一句有态度的 tagline，比如"用自然语言写出来的产品"，配一个流体动效，鼠标划过要有涟漪效果，类似蘸了墨的毛笔在清水中划过的效果，整体色调同页面主题色
 - 作品卡片网格：这是主体。每个卡片包含：
   - 产品截图/预览图
   - 项目名称
   - 一句话简介
   - 技术标签（如 React / Python / Electron）
   - 状态标签（已上线 / 开发中 / 实验性 / Archive）
   - hover 时浮出"查看详情"和"在线体验"两个按钮
 - 卡片布局选择：等高卡片 + CSS Grid 自适应列数（桌面 3-4 列，平板 2 列，手机 1 列）。

 详情浮出卡片：
 点击卡片浮出卡片，分为几个信息区块：
 - 产品展示区：大图轮播或视频演示 + 在线体验链接（新窗口打开）
 - 项目信息：名称、一句话描述、技术栈标签、创建时间、状态
 - 功能说明：这个工具解决什么问题、核心功能列表
 - 构建故事：原始 Prompt 是什么、用了什么 AI 工具（Cursor / Copilot / TRAE / ChatGPT 等）、迭代了几轮、遇到什么有趣的技术决策
 - 右上角的“×”关闭按钮
```

然后让AI`为该页面生成一份详尽的设计规范Skills`，得到`spec.md`

转到 TRAE Work 的 Code模式，链接本GitHub仓库，使用以下提示词：

```text
根据spec.md，创建index.html。
网站名为AI工具集，要同步修改页面title和顶部导航栏左侧显示名称。顶部导航栏分类根据已有的工具类型动态增减，若还没有工具则只显示“全部”分类项。
页脚居中小字显示“© yyyy Banana Y.X.”，链接指向，且在新标签页中打开，年份要更新到现在的年份。
我会上传工具的html文件、工具截图、构建故事给你，你需要将工具上架显示为作品卡片，根据html工具的内容和功能提取工具名称、一句话简介、技术标签、功能说明。
我上传给你的文件放在项目/tools目录下，图片放在/img目录下，“在线体验”按钮使用相对路径在新标签页跳转到工具对应的html链接。
修改后的代码直接push到main分支而不提交PR
```
